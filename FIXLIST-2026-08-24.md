## 2. The exam-structure system

**Verified SERP anchor:** searching "madhu and kavitha purchased a new house" returns exclusively *question-level* pages — Brainly, [Sarthaks](https://www.sarthaks.com/2854779/madhu-and-kavitha-purchased-new-house-for-000-due-some-economic-problems-they-sold-the-house), Vedantu `/question-answer/`, Numerade, Allen QnA. **URL patterns** (consistent with existing `/learn/{subject}/{board}`):
- CBSE: `/cbse/class-10/maths/chapter-1-real-numbers/` — one page per chapter, every exercise question an anchor (`#ex-1-2-q3`); promote proven GSC queries to standalone `/cbse/questions/{slug}` pages

- GCSE: `/gcse/aqa/biology/{topic}-model-answers/` + `/gcse/{board}/command-words/`
- AP: `/ap/calculus-ab/frq/{topic}/`
- Cambridge: `/igcse/{subject}/{topic}-questions/`

**Chapter/topic page template** (~2,500–3,000w). Verified competitor bar: Tiwari's Class 10 Ch 1 page is ~8–10k words — verbatim exercises, 21 PYQs, assertion-reason, case studies, tiered practice tests, PDFs, FAQ. We can't out-bulk it; we beat it on what it lacks:
1. Intro: what the chapter tests + exam-mapping table (concept → board years asked — facts)
2. Concept-in-60-seconds
3. Per-question blocks: paraphrased stem → full original solution → "where marks are lost" → one original variant
4. Original mixed test (printable)
5. Flashcard recap block (carries Quiz schema, §4)
6. **AI hook Tiwari can't match:** "solve a variant with the [board] solver" button per question, deep-linking the tool with a preset prompt

**Internal-linking rules:** every exam page links prev/next chapter, its subject hub, its board tool-landing, 2–3 siblings; hubs become chapter indexes linking down; retro-fit one contextual link from each of the 165 blog posts into an exam page; retitle hubs to student query order ("Maths Help" not "Help in Study Math" — your audit's accounting-hub-at-position-9 finding makes hubs the cheapest wins); nothing >3 clicks from home.

Then WAEC (lowest-authority competitor set — inference), Cambridge IGCSE topics, AP FRQ, GCSE model answers last (SaveMyExams, 4.75M visits/mo, is the incumbent — hardest).
